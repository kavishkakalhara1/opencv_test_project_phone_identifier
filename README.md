# Phone Identifier

This project is a real-time object detection application designed to identify objects, with a focus on phones, using a webcam and the MobileNetV2 model from TensorFlow. It displays a live video feed, highlights detected objects with a bounding box, and shows confidence scores. Users can capture screenshots, which are saved locally. The app features live object detection using MobileNetV2 pre-trained on ImageNet, a bounding box with label and confidence score around the center crop, screenshot functionality, a Tkinter-based UI with live feed and buttons, and customizable settings like frame size.

To run this, you need Python 3.7+ and the following libraries: `tkinter` (included with Python), `Pillow` (`pip install Pillow`), `opencv-python` (`pip install opencv-python`), `numpy` (`pip install numpy`), and `tensorflow` (`pip install tensorflow`). Save the script as `phone_identifier.py`, install dependencies with `pip install Pillow opencv-python numpy tensorflow`, and ensure a webcam is connected. Then, run `python phone_identifier.py`. The app will open, showing the webcam feed. Every 5 frames, it analyzes the center crop to detect objects, displays the object name and confidence score, and lets you click "Take Screenshot" to save frames to a `screenshots/` directory or "Quit" to exit.

You can customize settings: frame dimensions (default: 640x480), crop size (default: 224), detection interval (default: 5 frames), and screenshot directory (default: "screenshots"). The app uses MobileNetV2, which may not be phone-specific but works for general objects. Ensure good lighting for better accuracy. Screenshots are saved as PNGs with timestamps. If the webcam fails, an error is printed, and the app exits. For issues, check webcam connection, TensorFlow compatibility (e.g., 2.10+ for Python 3.7-3.10), or increase the detection interval for better performance.
